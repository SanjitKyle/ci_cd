📘 WEEK 1: Fundamentals

1. The Basic Workflow & Branch Filtering

Triggering a job only when pushing to the main branch.

name: Practice 1 - The Basics
on:
  push:
    branches:
      - main
  workflow_dispatch:

jobs:
  my_first_test:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout repo
        uses: actions/checkout@v4
        
      - name: print
        run: |
          echo "Practice 1 is successfully deployed"

2. Ignoring Paths (Saving Money)

Telling GitHub NOT to run the pipeline if we only edit a specific file.

name: Practice - Ignore Paths
on:
  push:
    paths-ignore:
      - '**.md'     # Ignores all markdown files
      - 'test.js'   # Ignores the specific test.js file

jobs: 
  ignore_test:
    runs-on: ubuntu-latest
    steps: 
      - run: |
          echo "This will not run if I only edit test.js!"

3. Environment Variables & Secure Secrets

Passing public variables to a job, and secure passwords to a step.

name: Practice 2 - Secrets
on: [workflow_dispatch]

jobs:
  practice_two:
    runs-on: ubuntu-latest
    env:
      APP_ENV: "Production"
    
    steps:
      - name: checkout repo
        uses: actions/checkout@v4
        
      - name: Print variables and secrets
        env:
          MY_SECURE_PASSWORD: ${{ secrets.MYTESTPASS }}
        run: |
          echo "The application is running in : $APP_ENV"
          echo "My super secrets password is : $MY_SECURE_PASSWORD"

4. Multi-Job Pipelines & Exit Codes

Connecting two jobs together, and watching one fail intentionally.

name: Practice 3 & 4 - Multi Job & Quality Gate
on: [workflow_dispatch]

jobs:
  test_job:
    runs-on: ubuntu-latest 
    steps:
      - name: Test the code
        run: |
          echo "Testing code..."
          exit 1   # This crashes the job intentionally!

  deploy_job:
    runs-on: ubuntu-latest
    needs: test_job  # This job will be CANCELLED because test_job crashed
    steps:
      - name: Deploy the application 
        run: |
          echo "The application is deployed successfully"

🚀 WEEK 2: Production Optimization

5. The Matrix Strategy

Testing multiple versions of Node.js simultaneously.

name: Week 2 Practice 1 - Matrix 
on: [workflow_dispatch]

jobs:
  test_multiple_version:
    runs-on: ubuntu-latest
    strategy:
      matrix:
        node_version: [18, 20, 22]

    steps:
      - name: Setup node js 
        uses: actions/setup-node@v4
        with:
          node-version: ${{ matrix.node_version }}
          
      - name: Print Version
        run: |
          echo "Testing node js version ${{ matrix.node_version }}"
          node -v

6. Build Artifacts

Teleporting a file from Job 1 to Job 2 using Cloud Storage.

name: Week 2 Practice 2 - Artifacts
on: [workflow_dispatch]

jobs:
  build_job:
    runs-on: ubuntu-latest
    steps:
      - run: echo "My production backend code!" > backend.txt
          
      - name: Upload Artifact
        uses: actions/upload-artifact@v4
        with:
          name: my-package
          path: backend.txt

  deploy_job:
    needs: build_job
    runs-on: ubuntu-latest
    steps:
      - name: Download Artifact
        uses: actions/download-artifact@v4
        with:
          name: my-package
          
      - run: cat backend.txt

7. Manual Caching

Saving a specific folder manually so we don't have to download it twice.

name: Week 2 Practice 3 - Caching 
on: [workflow_dispatch]

jobs:
  caching_job:
    runs-on: ubuntu-latest 
    steps:
      - name: Try to load cache 
        uses: actions/cache@v4
        id: vault_check 
        with:
          path: 'src'
          key: my-cache-v1

      - name: Simulate downloading (cache miss)
        if: steps.vault_check.outputs.cache-hit != 'true'
        run: |
          echo "Cache not found! Doing a heavy downloading"
          sleep 10
          mkdir -p src
          echo "Downloaded data" > src/data.txt

8. Real-World Built-in Caching

The Senior way to cache node_modules automatically in 1 line of code.

name: Real World Built-in Cache
on: [workflow_dispatch]

jobs:
  build_backend:
    runs-on: ubuntu-latest
    steps:
      - name: Checkout Code
        uses: actions/checkout@v4

      - name: Setup Node.js & Automatically Cache node_modules
        uses: actions/setup-node@v4
        with:
          node-version: '20'
          cache: 'npm'  # The magic shortcut!

      - name: Install Real Dependencies
        run: npm install
